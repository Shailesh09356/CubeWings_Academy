# ❒ 🪽 CubeWings Academy

Welcome to **CubeWings Academy** — a growing collection of practical notes, commands, cheat sheets, concepts, and hands-on knowledge collected while learning **Cybersecurity, Networking, Cloud, Linux, Docker, and IT Infrastructure**.

This repository is built with a simple idea:

**If I learn something useful, I document it.  
If I practice something, I save it.  
If it can help someone else, I share it.**

## 🚀 What is CubeWings Academy?

CubeWings Academy is my personal **technical knowledge base and learning archive**.

Instead of keeping everything scattered across bookmarks, notebooks, screenshots, and random files, useful knowledge is organized here so it can be:

- 🧠 Revisited whenever needed
- 🔍 Searched quickly
- 🛠️ Practiced through examples
- 📚 Used for interview preparation
- 🌎 Shared with other learners
- 📈 Continuously improved as I learn more

This repository will evolve alongside my learning journey.

## 📖 How I Learn

My learning cycle is simple:

```text
        ┌───────────┐
        │   LEARN   │
        └─────┬─────┘
              ↓
        ┌───────────┐
        │  PRACTICE │
        └─────┬─────┘
              ↓
        ┌───────────┐
        │   BREAK   │
        └─────┬─────┘
              ↓
        ┌───────────┐
        │   FIX     │
        └─────┬─────┘
              ↓
        ┌───────────┐
        │ DOCUMENT  │
        └─────┬─────┘
              ↓
        ┌───────────┐
        │   SHARE   │
        └─────┬─────┘
              │
              └──────────→ Repeat
```

Because **understanding something is good, but being able to explain and troubleshoot it is better.**

## 🧪 Practical First

Whenever possible, the content here focuses on:

**Concept → Command → Example → Practice → Troubleshooting**

The goal isn't just to memorize commands.

The goal is to understand:

> **What is happening? Why is it happening? How do I verify it? How do I fix it?**
